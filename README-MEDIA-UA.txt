ВСТАНОВЛЕННЯ
1. Зробіть резервну копію поточного сайту.
2. Розпакуйте архів. index.html, media.html, music.html, папки assets та images знаходяться одразу в його корені.
3. Завантажте файли та папки в корінь чинного GitHub Pages — туди, де вже лежить index.html. Погодьтеся на заміну однойменних файлів. НЕ створюйте всередині репозиторію ще одну папку media-v4 або my-website-main.
4. Після завершення публікації GitHub Pages відкрийте пункт «Медіа» в меню й оновіть сторінку без кешу.

Головна сторінка, біографія, концерти, новини та контакти збережені з вашого початкового архіву. Зміни знаходяться в медіарозділі.

ЩО ВИПРАВЛЕНО ПІСЛЯ V3
— Початковий вміст кожної сторінки записаний у HTML, а не існує лише в JavaScript.
— Перемикання медіа на сайті змінює вміст без перебудови спільної шапки та навігації.
— Компактний плеєр п’єси знаходиться праворуч від обкладинки.
— Кнопка додавання та ціна розташовані нижче; окремого вбудованого переглядача PDF немає.
— Клік по обкладинці відкриває зразок у модальному вікні.
— Під п’єсою знаходиться горизонтальна стрічка інших нот.
— При виборі фото або відео карусель зберігає позицію прокрутки.
— У фото працюють стрілки клавіатури, свайпи головного фото та навігація у відкритому перегляді.
— Кошик зберігається, не дублює одну п’єсу та рахує суму з даних каталогу.
— Адреси CSS і JavaScript містять версії, щоб браузер завантажив нові файли.
— Архів містить тільки публічні файли сайту; повних PDF немає.

ОПЛАТА
Приймання платежів mono та видача повного PDF ще не підключені.
Кошик працює для вибору матеріалів, але не створює платіж і не списує кошти.
Повні PDF зберігайте окремо; не завантажуйте їх у публічний репозиторій.

ПЕРЕВІРКА
Перевірено виконання JavaScript у DOM-середовищі: пряме відкриття 12 основних URL,
переходи, мови, модальне вікно, кошик, аудіокерування та збереження прокрутки каруселей.
Перевірено локальні ресурси, унікальність ID, ціни та відсутність повних PDF.
Це не перевірка візуального вигляду у реальному Safari/Chrome та не перевірка
зовнішньої доступності YouTube. Для фінальної перевірки відкрийте сайт після публікації.
